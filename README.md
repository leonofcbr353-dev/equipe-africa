# Equipe África — FACE

Site estático feito com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — página principal
- `css/global.css` — estilos globais
- `css/home.css` — hero, destaques e seção sobre
- `css/intro.css` — abertura/intro
- `js/intro.js` — sequência da abertura
- `assets/equipe-africa-logo.png` — imagem inicial substituível

## Como abrir

Abra `index.html` diretamente no navegador.

Não é necessário instalar Node.js, Python ou qualquer outra linguagem/runtime.

## Sequência da abertura

- A — 1s
- FACE — 1s
- É — 1s
- NOSSA! — 2,5s
- No último segundo: piscadas aceleradas + tremor
- Transição final em expansão para revelar o site
